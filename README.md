# ГАЙД ПО СПАСЕНИЮ ОТ CLANG-FORMAT
## Первое, клонируем репозиторий( git clone https://github.com/ClangFormat-21/auto.git
## Второе, берем отсюда файлик pre-commit, и закидываем его в ваш проект в папку .git/hooks
## Эта папка может быть скрытой, что бы найти ее в терминале пропишите ls -a или если хотите через файловый менеджер, то нужно справа сверху нажать на три полоски и show hidden files
## После этих не сложных манипуляций, при попытке сделать коммит, у вас будет автоматически использоваться clang-format -n и проверять есть ли ошибки, а потом clang-format -i что бы эти ошибки сразу же исправились.
